# Raw source files

วางไฟล์ `.txt` (UTF-8) ที่คัดลอกจากเอกสารกฎหมายไว้ในโฟลเดอร์นี้
ตั้งชื่อให้เรียงตามลำดับที่ต้องการ: `book1.txt`, `book2.txt`, …

ไฟล์เหล่านี้ถูก commit เข้า repo โดยตั้งใจ เพื่อให้ตรวจสอบย้อนหลังได้ว่า
ข้อมูลใน `src/data/generated/` มาจากข้อความต้นทางแบบใด

ดูวิธีใช้ที่ [`docs/DATA_IMPORT.md`](../../docs/DATA_IMPORT.md)
