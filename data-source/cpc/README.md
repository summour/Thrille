# ตัวนำเข้าตัวบทดิบ: ประมวลกฎหมายวิธีพิจารณาความแพ่ง (ป.วิ.พ.)

โฟลเดอร์นี้รองรับการนำเข้าตัวบทกฎหมายดิบ (.txt) โดยระบบรองรับโครงสร้างต่อไปนี้:

- **คำปรารภ** (วางไว้บรรทัดแรก ตามด้วยข้อความคำปรารภ)
- **ภาค** (เช่น `ภาค ๑ บทบัญญัติทั่วไป`)
- **ลักษณะ** (เช่น `ลักษณะ ๑ หลักทั่วไป`)
- **หมวด** (เช่น `หมวด ๑ เขตอำนาจศาล`)
- **ส่วนที่** (เช่น `ส่วนที่ ๑ ...`)
- **มาตรา** (เช่น `มาตรา ๑`, `มาตรา ๒ ทวิ`)

### วิธีใช้งาน

1. คัดลอกข้อความตัวบทดิบมาใส่ในไฟล์ `.txt` ในโฟลเดอร์นี้ (เช่น `cpc.txt`)
2. รันคำสั่งตรวจสอบ:
   ```bash
   npm run import:cpc:check
   ```
3. นำเข้าและแปลงเป็นฐานข้อมูลใช้งานจริง:
   ```bash
   npm run import:cpc
   ```
   ไฟล์ JSON ผลลัพธ์จะถูกสร้างและอัปเดตที่ `src/data/generated-cpc/` โดยอัตโนมัติ
